# Contributing

Itamos MCP Tools is free for personal and open-source use.

If you find a bug, open an issue with a minimal reproduction. If you have an improvement, open a PR with a clear description of what it changes and why.

## Areas we are actively working on

- Benchmark results: the harness is complete, results are being collected
- Additional language support in master_architect
- Hosted public sandbox endpoint at mcp.itamos.eu
- web_skeleton coverage of JS-heavy SPAs

## What we are not looking for right now

Changes to the core segment addressing model or the SQLite schema: these are stable and any change has wide downstream effects. Raise an issue first.
